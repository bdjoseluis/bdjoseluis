09/19 · la ficha
logica-condicional

Un camino distinto según cómo llegó

Formulario web

Entra por nuestro endpoint → se crea la ficha en Odoo → bot de WhatsApp en <1 min → si no hay respuesta en 1h, se genera tarea de llamada → arranca secuencia de 14 días.

WhatsApp directo

El bot cualifica con preguntas básicas → actualiza o crea la ficha → si no agenda cita, entra en la misma secuencia de seguimiento.

Llamada entrante

Queda registrada al colgar → WhatsApp de resumen automático → recordatorio si no hay cita confirmada en 48h.

flujo_entrada.js
// script propio — resumen del flujo de entrada
on('nuevo_lead', async (lead) => {
  await odoo.crear('crm.lead', lead);
  await whatsapp.enviar(lead.tel, plantilla.bienvenida);
  await esperar('1h');
  if (!lead.respondio) odoo.crearTarea('Llamar');
  secuencia.iniciar(lead, '14_dias');
});

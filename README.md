## 🔐 Seguridad

El máster no se queda en teoría, sale código:

- **[DevSec Scanner](https://github.com/bdjoseluis/devsec-scanner)** — auditoría externa de un dominio
  (DNS, SPF/DMARC, TLS, puertos, cabeceras) que devuelve nota A–F e informe en JSON, Markdown y HTML.
  Python puro, sin dependencias.
- **[PromptReaper](https://github.com/bdjoseluis/promptreaper)** — escáner de chatbots LLM contra el
  OWASP Top 10 for LLM Apps, con batería de ataques **en español**: los guardarraíles se entrenan
  sobre todo en inglés y ceden más fácil en otros idiomas. Incluye puerta de consentimiento.
- **[B-DevOps](https://github.com/bdjoseluis/b-devops)** — ciberinteligencia OSINT: dominio → recon
  y CVEs → informe.
